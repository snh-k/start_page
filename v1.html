                ℹ️ 데이터 저장 및 보관 안내
                입력된 모든 설정과 링크 데이터는 **사용자 자신의 컴퓨터(브라우저 캐시 및 LocalStorage)**에 저장됩니다. 서버에 저장되는 것이 아니기 때문에 사용자 본인에게만 보여집니다.

                💾 데이터 백업 및 복원

                저장해둔 메모, 즐겨찾기, 체크리스트, 달력 일정, 설정 값, 사용자 블록 링크를 백업 파일(.json)로 저장하거나 백업 파일로부터 복원합니다.

                🔗 메인 블록 사용자 링크 설정

                홈 화면의 각 카테고리 블록에 나만의 링크를 추가합니다. 추가된 링크는 메인 화면에 기존 스타일 그대로 표시되며, 순서는 ☷ 드래그 또는 ↑↓ 버튼으로 변경할 수 있습니다.

                      🛒 쇼핑 & 이벤트 링크 추가

                        ⚔️ 마영전 캐릭터 수 설정

                        '마영전 임무 리스트' 및 '그림자의 성채' 블록에 표시할 캐릭터 수를 설정합니다(입력 범위: 1~6).

                        ☀️ 유틸리티 날씨 검색 설정

                        '유틸리티' 블록에 표시될 날씨 링크의 이름과 클릭 시 검색될 실제 네이버 검색어를 설정합니다.

                        🌫️ 대기환경정보 링크 설정

                        '유틸리티' 블록에 표시될 대기환경정보 링크의 이름과 클릭 시 바로 이동할 웹 주소(URL)를 설정합니다.

                        ⌨️ 키보드 단축키 안내

                        입력창(검색창, 메모 등)에 커서가 있지 않은 상태에서 숫자키를 누르면 해당 페이지로 즉시 이동합니다.

                        • 1 : 홈 (Home)
                        • 2 : 체크리스트
                        • 3 : 달력
                        • 4 : 마영전
                        • 5 : 메모
                        • 0 : 설정
